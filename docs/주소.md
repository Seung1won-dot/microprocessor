## 자주 쓰는 명령

맥미니
```bash
# 서버 폴더
cd ~/"3학년 2학기"/캡스톤/cafeteria-server
# 서버 재시작 (server.py를 바꿨을 때)
launchctl kickstart -k gui/$(id -u)/kr.sch.cafeteria
# 서버 상태 확인
curl -s http://localhost:8000/api/latest; echo
# 공개 끄기 / 다시 켜기
tailscale funnel reset
tailscale funnel --bg 8000
```

라즈베리파이
```bash
# 상태
systemctl status people-count push-counts --no-pager
sudo journalctl -u people-count -n 10 --no-pager
# 재시작 (people_count.py를 바꿨을 때)
sudo systemctl restart people-count
```

코드를 고쳐서 기기에 반영하는 순서는 [HANDOFF 14장 "코드 수정 반영"](HANDOFF.md#코드-수정-반영-저장소--기기)에 있습니다. 저장소 파일에는 IP·비밀번호를 가려 둔 줄이 있어서 **기기 파일에 그대로 덮어쓰면 안 돼요.**
