### ⚠️ 제출본에서 누락된 2가지 — **새로 만드는 게 아니라 복원하는 것**

수업 필수 요건은 그대로입니다. **하나라도 빠지면 제안서 반려**이고, 심사는 **4주차**입니다.

제출된 요약서 본문에는 **인터럽트와 AI 3초 폴백 문단이 빠져 있습니다.**
다만 이 둘은 **[신청서_요약서](신청서_요약서.md) 원고에 이미 설계되어 있었고**, 분량을 줄이는 과정에서 잘려나간 것입니다.
따라서 **없던 것을 새로 만드는 게 아니라, 원고의 설계를 제안서에서 되살리면 됩니다.**
제안서는 신청서와 별개 문서이므로 이 정도 구체화는 **주제 변경이 아닙니다.**

| 요건 | 상태 | 메모 |
|---|---|---|
| ① 센서 입력 | ✅ | 카메라 2대 (+ 복원 시 IR 빔브레이크 1쌍) |
| ② MCU 처리 | ✅ | 아두이노 UNO — 시리얼 수신 · 상태 머신 · LED 신호등 구동 |
| ③ AI 판단 | ✅ | 경량 객체 검출 **온디바이스**(라즈베리파이) — 좌석 점유 판정 |
| ④ 액추에이터 | ✅ | 입구 LED 신호등 |
| **인터럽트 최소 1곳** | 🔁 **복원 필요** | 원고: *출입구 통과 0.3초 → 폴링 누락 → **외부 인터럽트 필수*** |
| **AI 3초 폴백** | 🔁 **복원 필요** | 원고: *AI 무응답 → **출입 카운트 기반 추정** → 시간대별 평균 + "확인 불가"* |
| 실존 문제 근거 | ⬜ | 점심 실측 수치 필요 (제안서에 숫자로) |

**복원 방법 (제안서 심사 전까지)**

- **인터럽트**: 입구에 **IR 빔브레이크 1쌍(약 1.5만원)** 을 두어 출입 인원을 **외부 인터럽트**로 카운트.
  통과 시간이 0.3초라 폴링으로는 누락된다 → *"인터럽트여야만 하는 이유"* 가 그대로 성립합니다.
  출입 카운트는 **좌석 점유율 보정용 보조 지표**이자 **영상 인식 실패 시의 대체 지표**입니다.
  추가로 아두이노에 **타이머 인터럽트 워치독**(패킷 N초 미수신 → 안전 상태 전환)을 얹으면 인터럽트 근거가 두 겹이 됩니다.
- **AI 3초 폴백**: 검출 무응답 3초 → **출입 카운트 기반 추정으로 전환** → 그것도 불가하면 **시간대별 평균 + "확인 불가"** 표시.
  웹에 *마지막 갱신 시각*을 띄우기로 했으므로 화면 설계와 그대로 맞물립니다.
- **폴백 원칙**: 애매하면 **더 혼잡한 쪽**으로 표시 (헛걸음 손실이 더 큼).

> 💡 이 복원은 **시연에도 직결**됩니다. 라즈베리파이 전원을 뽑아도 아두이노가 출입 카운트만으로 LED 신호등을 계속 구동하는 장면이
> **AI 폴백의 직접적인 증거**가 됩니다. (요약서 원고 1절에 이미 그렇게 써 두었습니다)

## 2. 시스템 구성 (확정)

```
카메라 2대 ──→ 라즈베리파이 ──(시리얼)──→ 아두이노 UNO ──→ 입구 LED 신호등
  구역 분할       경량 검출 모델            3단계 수신          녹 / 황 / 적
  천장→하향       온디바이스 추론           상태 머신 · LED 구동
                       │                         ↑
                       │        IR 빔브레이크 ───┘  (복원: 출입 카운트 = 외부 인터럽트)
                       │        통과 0.3초          보조 지표 + AI 폴백 시 대체 지표
                       │
                       └──→ 웹 ──(QR)──→ 모바일 브라우저
                                          신호등 + 점유율 + 마지막 갱신 시각
                                          (주기 자동 갱신, 새로고침 불필요)
```

- 카메라 2대는 **서로 다른 구역**을 촬영해 사각지대를 줄인다
- 혼잡도 = **사용 중 좌석 / 전체 좌석** → 여유 / 보통 / 혼잡 3단계
- 아두이노 UNO는 **수업 배부 보드 사용 (0원)**
- LED 신호등은 **웹 서버 장애 시에도 유지되는 이중화** 역할

### 프라이버시 설계 (그대로 유지)

1. 카메라는 **천장에서 아래로** → 얼굴이 아닌 **상부 실루엣만**
2. **영상 비저장**
3. **온디바이스 처리** — 영상이 네트워크로 나가지 않음
