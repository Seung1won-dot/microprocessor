# 라즈베리파이 5 + Tapo C200 세팅 · 인원수 추론 (10/14)

> 2026-10-14 회의와 그날 작업 기록. 라즈베리파이 5가 Tapo C200 영상을 받아 **파이 안에서** 사람 수를 추론하고 결과를 웹페이지로 보여주는 데까지 했다. 원격 접속은 Tailscale을 쓴다.
> 시스템 전체 구성 · 부품 · 서버/웹 계획은 [구현 계획 (10/3)](구현계획_1003.md)이 기준이고, 이 문서는 **실제로 설치하고 돌려 본 절차와 측정값**이다.

> ⚠️ 이 문서와 코드에는 실제 비밀번호를 넣지 않는다. `<...>`로 표시된 값은 각자 환경에 맞게 바꿔 쓴다.

## 오늘 한 것 요약

- 라즈베리파이 5에 OS 설치, 업데이트, Tailscale 원격 접속 설정
- 인터넷 Wi-Fi 프로필(아이폰 핫스팟 · 학교 Wi-Fi SCH) 등록
- 파이 내장 Wi-Fi 하나로 **인터넷 연결(wlan0) + 카메라 전용 핫스팟 `cap`(uap0)** 동시 사용 성공
- Tapo C200을 `cap`에 연결하고 RTSP로 캡처 확인
- 부팅 시 `cap` 자동 시작 · 카메라 IP 고정 설정 등록 (재부팅 후 실제 동작은 아직 확인 전)
- YOLO11n(ONNX)으로 파이에서 인원수 추론 → 박스 · 인원수 웹 표시, `/count` JSON 제공
- 카메라 1대 연속 추론 시 CPU · 메모리 측정

회의에서 정한 다음 할 일은 [11절](#11-다음-할-일)에 있다.

## 1. 시스템 구성

```
[Tapo C200 카메라] --(Wi-Fi: cap, RTSP)--> [Raspberry Pi 5] --(인터넷 Wi-Fi + Tailscale)--> [노트북 브라우저]
                                            ├─ wlan0 : 인터넷 Wi-Fi 연결 (아이폰 핫스팟 / 학교 Wi-Fi)
                                            ├─ uap0  : Pi 자체 핫스팟 "cap" (카메라 전용)
                                            └─ people_count.py : 영상 수신 → YOLO 추론 → 인원수 웹 표시
```

| 항목 | 값 |
|---|---|
| 보드 | Raspberry Pi 5 |
| OS | Raspberry Pi OS 64-bit (Debian 13 기반) |
| 카메라 | TP-Link Tapo C200 (2.4GHz 전용, RTSP 지원) |
| 원격 접속 | Tailscale (`ssh <USER>@<PI_TAILSCALE_IP>`) |
| 카메라 네트워크 | Pi 핫스팟 `cap` (<내부 주소>/24) |
| 추론 모델 | YOLO11n (ONNX, OpenCV DNN) |

## 2. OS 설치 (Raspberry Pi Imager)

1. 노트북에 Raspberry Pi Imager 설치
2. 장치: Raspberry Pi 5 / OS: Raspberry Pi OS (64-bit) / 저장소: microSD
3. 사용자 지정
   - 호스트 이름: `RaspberryPi5`
   - 로컬화: Seoul / Asia/Seoul / 키보드 kr

   - Wi-Fi: 처음 접속할 네트워크
   - SSH 사용: 비밀번호 인증
4. 쓰기 → SD카드를 Pi에 꽂고 전원 연결 (초록 LED 깜빡임 = 부팅 중)

## 3. 첫 접속과 업데이트

```bash
# 같은 Wi-Fi일 때 (노트북)
ssh <USER>@RaspberryPi5.local

# 업데이트 후 재부팅
sudo apt update && sudo apt full-upgrade -y
sudo reboot
```

종료할 때는 `sudo shutdown now` → 초록 LED가 꺼지고 빨간 LED만 남으면 전원 분리.

## 4. Tailscale (원격 접속)

```bash
curl -fsSL https://tailscale.com/install.sh | sh
sudo tailscale up          # 출력된 링크를 브라우저에서 열어 로그인
tailscale ip -4            # 100.x.x.x 주소 확인
```

- 관리 페이지 → Machines → Pi의 `...` → **Disable key expiry** (화면 없는 기기라 만료되면 접속 불가)
- 이후 어디서든 `ssh <USER>@<PI_TAILSCALE_IP>`로 접속
- 노트북에도 Tailscale 앱 설치 · 같은 계정 로그인 필요

## 5. 인터넷 Wi-Fi 프로필

```bash
# 일반 WPA2 (아이폰 핫스팟 등) – SSID는 영어로 쓰는 게 안전
sudo nmcli connection add type wifi con-name iphone ssid "<HOTSPOT_SSID>" \
  wifi-sec.key-mgmt wpa-psk wifi-sec.psk "<HOTSPOT_PW>"

# 학교 Wi-Fi (WPA2-Enterprise / 802.1X)
sudo nmcli connection add type wifi con-name school ssid "SCH" \
  wifi-sec.key-mgmt wpa-eap 802-1x.eap peap 802-1x.phase2-auth mschapv2 \
  802-1x.identity "<ID>" 802-1x.password "<PW>"

# 확인
nmcli connection show --active
nmcli device wifi list --rescan yes
```

**아이폰 핫스팟 메모**

- 핫스팟 이름 = 아이폰 기기 이름 (설정 → 일반 → 정보 → 이름)
- **호환성 최대화** 켜기 → 2.4GHz
- 핫스팟 설정 화면을 열어두지 않으면 목록에서 숨겨질 수 있음

## 6. Tapo C200 연결

1. Tapo 앱 → `+` → C200 → Wi-Fi로 `cap` 선택
   - 핫스팟을 켠 아이폰으로 설정하면 설정 중 핫스팟이 꺼지므로 **다른 휴대폰으로 설정**
2. 카메라 설정 → 고급 설정 → **카메라 계정**에서 RTSP 계정 생성
   - 초기화하면 RTSP 계정도 지워짐 → 다시 생성
   - 계속 401 Unauthorized면 Tapo Lab → Third-Party Compatibility 확인

**RTSP 주소**

| 화질 | 주소 |
|---|---|
| 고화질 | `rtsp://<CAM_USER>:<CAM_PW>@<CAM_IP>:554/stream1` |
| 저화질 | `rtsp://<CAM_USER>:<CAM_PW>@<CAM_IP>:554/stream2` |

```bash
# 캡처 테스트 (Pi)
sudo apt install -y ffmpeg
ffmpeg -rtsp_transport tcp -i "rtsp://<CAM_USER>:<CAM_PW>@<내부 주소>:554/stream2" -update 1 -frames:v 1 cam1.jpg

# 노트북으로 가져오기 (노트북 PowerShell에서 실행!)
scp <USER>@<PI_TAILSCALE_IP>:~/cam1.jpg .
```

## 7. Pi 자체 핫스팟 cap (내장 Wi-Fi 하나로 연결 + 핫스팟 동시 사용)

Pi 5 내장 Wi-Fi는 managed 1개 + AP 1개 동시 사용을 지원한다. 단, `#channels <= 1`이라 **핫스팟 채널이 인터넷 Wi-Fi 채널과 같아야 한다.**

```bash
# 지원 확인
iw list | grep -A4 "valid interface combinations"

# 가상 AP 인터페이스 생성
sudo iw dev wlan0 interface add uap0 type __ap
sudo nmcli device set uap0 managed yes

# 현재 인터넷 Wi-Fi 채널 확인
iw dev wlan0 info | grep channel

# 핫스팟 생성 (채널은 위에서 확인한 값)
sudo nmcli connection add type wifi ifname uap0 con-name cam-ap autoconnect no ssid cap mode ap \
  802-11-wireless.band bg 802-11-wireless.channel 6 ipv4.method shared \
  wifi-sec.key-mgmt wpa-psk wifi-sec.psk "<CAP_PW>" \
  wifi-sec.proto rsn wifi-sec.pairwise ccmp wifi-sec.group ccmp wifi-sec.pmf disable
sudo nmcli connection up cam-ap

# 확인: wlan0 → iphone, uap0 → cam-ap
nmcli device status
sudo cat /var/lib/NetworkManager/dnsmasq-uap0.leases   # 카메라 IP/MAC
```

> Tapo C200은 2.4GHz 전용 → 인터넷 Wi-Fi도 2.4GHz여야 같은 채널로 핫스팟을 켤 수 있다.

## 8. 영구 설정 (부팅 시 자동으로 cap 켜기)

### 8-1. 부팅 시 uap0 생성

```bash
sudo tee /etc/systemd/system/uap0.service > /dev/null <<'UNIT'
[Unit]
Description=Create uap0 AP interface
After=sys-subsystem-net-devices-wlan0.device
Before=NetworkManager.service

[Service]
Type=oneshot
ExecStart=-/usr/sbin/iw dev wlan0 interface add uap0 type __ap
RemainAfterExit=yes

[Install]
WantedBy=multi-user.target
UNIT
sudo systemctl enable uap0.service
```

### 8-2. 인터넷 Wi-Fi 연결 시 같은 채널로 cap 자동 시작

```bash
sudo tee /etc/NetworkManager/dispatcher.d/90-cam-ap > /dev/null <<'SCRIPT'
#!/bin/bash
[ "$1" = "wlan0" ] || exit 0
[ "$2" = "up" ] || exit 0
(
  sleep 3
  CH=$(iw dev wlan0 info | awk '/channel/{print $2; exit}')
  [ -n "$CH" ] || exit 0
  if [ "$CH" -le 14 ]; then BAND=bg; else BAND=a; fi
  nmcli device set uap0 managed yes
  nmcli connection modify cam-ap 802-11-wireless.band "$BAND" 802-11-wireless.channel "$CH"
  nmcli connection up cam-ap
  logger "cam-ap started on channel $CH"
) &
SCRIPT
sudo chmod +x /etc/NetworkManager/dispatcher.d/90-cam-ap
```

### 8-3. 인터넷 Wi-Fi 2.4GHz 고정

```bash
sudo nmcli connection modify iphone 802-11-wireless.band bg
# 학교 Wi-Fi도 저장 후 동일하게 band bg 지정
```

### 8-4. 카메라 IP 고정 (MAC 기준)

```bash
sudo mkdir -p /etc/NetworkManager/dnsmasq-shared.d
echo "dhcp-host=<CAM1_MAC>,<내부 주소>" | sudo tee /etc/NetworkManager/dnsmasq-shared.d/cams.conf
# 카메라 추가 시 tee -a 로 줄 추가
```

### 8-5. 등록 확인

```bash
systemctl is-enabled uap0.service                                   # enabled
ls -l /etc/NetworkManager/dispatcher.d/90-cam-ap                     # -rwxr-xr-x
nmcli -g 802-11-wireless.band connection show iphone                 # bg
nmcli -g 802-11-wireless.ssid,802-11-wireless.band,802-11-wireless.channel connection show cam-ap
cat /etc/NetworkManager/dnsmasq-shared.d/cams.conf
```

## 9. 영상 스트리밍 / 인원수 추론

### 9-1. 설치 (Pi)

```bash
sudo apt install -y python3-opencv python3-flask
```

### 9-2. 모델 준비 (노트북에서 1회 → Pi로 복사)

```bash
pip install ultralytics

```

모델 파일만 노트북에서 만들고, **추론은 전부 Pi에서** 실행된다.

### 9-3. 실행

```bash
python3 people_count.py
# 브라우저: http://<PI_TAILSCALE_IP>:5000
```

| 파일 | 역할 |
|---|---|
| `view_cam.py` | (노트북) SSH 터널로 RTSP 직접 보기 |
| `pi_stream.py` | (Pi) RTSP 수신 → MJPEG 웹 스트리밍 |
| `people_count.py` | (Pi) RTSP 수신 → YOLO 추론 → 박스 · 인원수 표시, `/count` JSON 제공 |

**`people_count.py` 주요 설정**

| 변수 | 설명 |
|---|---|
| `CAMS` | 카메라 이름 → IP |
| `STREAM` | `stream1`(HD) / `stream2`(SD) |
| `CONF` / `NMS` | 검출 임계값 / 겹침 제거 임계값 |
| `INFER_INTERVAL` | 카메라별 추론 간격(초), CPU · 발열 절감 |
| `OUT_FPS` | 브라우저 전송 프레임 수 |

### 9-4. 측정 결과 (카메라 1대, 간격 없이 연속 추론)

- 사람이 겹치면 누락 발생 → `CONF` 낮추기 / `NMS` 올리기 / 카메라를 높은 곳에서 내려다보게 설치

## 10. 트러블슈팅 메모

| 증상 | 원인 / 해결 |
|---|---|
| `Could not resolve hostname xxx.local` | 다른 네트워크에 있음 → Tailscale IP로 접속 |
| `Connection timed out` (Tailscale) | 노트북 Tailscale 꺼짐 또는 Pi가 인터넷에 연결 안 됨 |
| `C:\...` 경로로 scp 실패 | Pi 안에서 실행함 → 노트북 PowerShell(`PS C:\>`)에서 실행 |
| Desktop 경로 오류 | OneDrive로 바탕화면 이동됨 → `.`(현재 폴더)로 받기 |
| 한글 SSID 검색 안 됨 | 인코딩 문제 → 핫스팟 이름을 영어로 |
| Tapo 앱에서 핫스팟이 안 보임 | 설정 중 아이폰 핫스팟이 꺼짐 → 다른 휴대폰으로 설정 |
| ffmpeg `401 Unauthorized` | RTSP 계정 불일치/초기화됨 → 앱에서 재생성 |
| ffmpeg `Failed to resolve 10.42.0.x` | x를 실제 IP로 바꾸지 않음 |
| ffmpeg 이미지 시퀀스 경고 | 무시 가능, `-update 1` 추가 |
| 노트북이 Pi 핫스팟 비밀번호 거부 | WPA2(RSN/CCMP, PMF 끔)로 고정해 다시 생성 |
| `cat ...leases: Permission denied` | `sudo` 필요 |
