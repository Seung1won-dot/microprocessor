"꽉 찼다"는 기준을 어떻게 정했나

인원 몇 명 이상을 혼잡으로 나눈 것이 아니라, 학생의 질문에서 출발해 기준을 직접 정의했습니다.

1문제 정의

몇 명 있나?→지금 가면 앉을 수 있나?

학생식당은 모르는 사람과 거의 합석하지 않습니다. 그래서 중요한 건 사람 수가 아니라 앉을 테이블이 남았는지입니다.

2사람 수만으로는 안 되는 이유

사람 수로 보면 · 95명 / 150석37% 남음 · 여유
실제 테이블 · 51곳 중 빈 곳0~1곳 · 혼잡

10/29 12:00 실제 기록. 4인석마다 1~2명씩 앉아, 좌석은 남아 보여도 앉을 테이블이 없었습니다.

3기준을 세 번 고쳤습니다

~ 10/28좌석 대비 인원

(좌석 − 인원) ÷ 좌석. 4인석에 2명만 앉아도 남은 2석은 실제로 안 쓰임

10/28 ~빈 테이블 비율

2인석과 6인석을 같은 1개로 셈. 자리를 찾아 서 있는 사람은 반영 못 함

10/29 ~ 지금점유 테이블 좌석 + 인원

테이블을 좌석 수만큼 세고, 서 있는 사람도 곧 앉을 수요로 반영

4지금 쓰는 계산

사용 좌석 = max( 점유 테이블의 좌석 합 , 식당 안 전체 인원 )
남은 좌석 비율 = (전체 좌석 − 사용 좌석) ÷ 전체 좌석
30% 이상 · 여유10~30% · 보통10% 미만 · 혼잡
  • 점유 테이블은 통째로 쓴다고 봅니다. 4인석에 1명이 앉아도 4석이 찬 것으로 계산합니다. 자리 비움(가방만 둔 자리)도 점유입니다.
  • 서 있는 사람이 더 많으면 그만큼 자리가 필요합니다. 배식을 받고 자리를 찾는 사람을 곧 앉을 수요로 봅니다.

5네 가지 상황으로 확인 (4인석 6개 = 24석 예시)

① 한산함둘 다 맞음
사람 수만 보면2명 / 24석
→ 92% 남음여유
우리 방식 · 사용 좌석max(4, 2) = 4석
→ 83% 남음여유
② 자리 찾는 사람이 많음서 있는 사람도 곧 앉을 수요
사람 수만 보면18명 / 24석
→ 25% 남음보통
우리 방식 · 사용 좌석max(8, 18) = 18석
→ 25% 남음보통
③ 4인석마다 1명씩사람 수만 보면 틀림
사람 수만 보면6명 / 24석
→ 75% 남음여유
우리 방식 · 사용 좌석max(24, 6) = 24석
→ 0% 남음혼잡
④ 정말 붐빔둘 다 맞음
사람 수만 보면28명 / 24석
→ 자리 부족혼잡
우리 방식 · 사용 좌석max(24, 28) = 28석
→ 4석 부족혼잡
점유 테이블 빈 테이블 앉은 사람 서 있는 사람
