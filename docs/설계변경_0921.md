# 설계 변경 — 2026.09.21

> **결정: 식당 입구 LED 신호등 설치를 폐기한다. 학생 안내는 QR → 모바일 웹 단일 채널로 간다.**
> 기준 문서: [과제확정_0914](과제확정_0914.md) · [예산회의_0916](예산회의_0916.md)
> **표시 방식에 관해서는 이 문서가 최신입니다.** 이전 문서의 "입구 LED 신호등" 서술은 전부 무효입니다.

---

## 1. 무엇을 바꿨나

| 항목 | 9/14 확정 | **9/21 변경** |
|---|---|---|
| 주 표시 채널 | QR → 모바일 웹 | **QR → 모바일 웹** (변동 없음) |
| 보조 표시 채널 | 식당 입구 소형 LED 신호등 | **없음 — 폐기** |
| 식당에 설치하는 것 | 카메라 2대 + 입구 LED 신호등 + 배선·전원 | **카메라 2대 + QR 스티커** |
| ④ 액추에이터 | 입구 LED 신호등 | **아두이노 시연 표시부** (신호등 LED + 7세그먼트 + 부저) |
| 아두이노 역할 | 시리얼 수신 · 상태 머신 · 입구 LED 구동 · 빔브레이크 인터럽트 | **동일 — 구동 대상만 시연 표시부로** |

웹 화면은 그대로 **신호등 형태(녹=여유 / 황=보통 / 적=혼잡)** 로 표현합니다.
즉 *신호등이라는 표현*은 유지되고, **물리 신호등을 식당에 설치하는 일만 없어집니다.**

---

## 2. 왜 뺐나

1. **식당 설치 협의가 프로젝트 전체의 병목** ([실행계획_0914](실행계획_0914.md) 1절 ④).
   카메라 설치 허가만으로도 쉽지 않은데, **전원·배선·고정이 필요한 표시 장치**까지 얹으면 승인 난이도가 올라갑니다.
   협의 대상을 **카메라 한 건**으로 줄입니다.
2. **학생이 실제로 쓰는 건 웹입니다.** 입구 LED는 이미 식당 앞에 도착한 사람에게만 보이고,
   우리 과제의 목적은 *"가기 전에 판단"* 입니다. 입구 표시는 목적에 직접 기여하지 않습니다.
3. **비용·공수 회수** — 고휘도 LED·MOSFET·외부 전원·실외형 하우징이 통째로 빠집니다. (3절)

## 3. 대신 ④ 액추에이터는 이렇게 채운다 — **빼면 반려입니다**

> [캡스톤디자인_전체정리 2-1절](캡스톤디자인_전체정리.md): 네 단계 중 **하나라도 빠지면 제안서 반려**.
> 반려 유형에 **"앱만 있는 프로젝트"** 가 명시되어 있어, 출력이 웹뿐이면 그대로 걸립니다.

**시연 표시부** — 아두이노 보드에 붙는 소형 표시 장치. **식당에 설치하지 않고, 부스·중간/최종 시연에서만 씁니다.**

| 구성 | 핀 | 역할 |
|---|---|---|
| 신호등 LED 녹·황·적 | D4 / D5 / D6 | 현재 3단계 상태 |
| 4자리 7세그먼트 + 74HC595 | D10 / D11 / D12 | **빈 좌석 수** 실시간 표시 |
| 능동 부저 | D9 | 단계 **전환 시점**에만 짧게 (상시 소음 없음) |

**이 구성의 장점**

- **3주차 실습(74HC595 · 7세그먼트 · 핀 확보 전략)과 그대로 연결됩니다.** 수업 내용을 과제에 쓴 지점이라 보고서·시연에서 점수가 됩니다.
- 워치독 안전 상태(황색 점멸)·AI 폴백 시연이 **그대로 유지**됩니다.
  라즈베리파이 전원을 뽑아도 아두이노가 출입 카운트만으로 표시부를 계속 구동하는 장면이 폴백의 직접 증거입니다.
- 설치 허가·외부 전원·방수 하우징이 **전부 불필요**해집니다.

**핀 재계산** — 시리얼 2 + 빔브레이크 1 + LED 3 + 부저 1 + 74HC595 3 = **10핀 / 20핀, 여유 10핀.**

## 4. 예산 영향

| 안 | 변경 전 | **변경 후** |
|---|---|---|
| A안 (3만원 규정 미적용) | 545,000 (여유 55,000) | **505,000 (여유 95,000)** |
| B안 (규정 적용 + 학과 대여) | 475,000 (여유 125,000) | **405,000 (여유 195,000)** |

신호등부 50,000 + 7세그먼트 10,000 → **시연 표시부 20,000** 으로 통합. 상세는 [예산회의_0916 3절](예산회의_0916.md).
남는 금액은 **카메라·렌즈·거치대 완성도**와 **예비 부품**으로 돌립니다. 정확도가 곧 평가 기준이기 때문입니다.

## 5. 신청서와 달라지는 점 — 미리 설명해 둘 것

제출한 신청서([신청서_요약서](신청서_요약서.md))에는 **"식당 입구 소형 LED 신호등"** 과
산출물 **"아두이노 LED 신호등부 1식"** 이 명시되어 있습니다. 제안서 심사에서 대조될 수 있으므로 **먼저 말하는 편이 안전**합니다.

> **설명 문구 (제안서·구두 공통)**
> "표시 채널을 QR 모바일 웹으로 단일화했습니다. 식당 내 표시 장치는 설치 허가·전원 확보가 필요해 일정 위험이 컸고,
> 학생이 이동 전에 판단한다는 과제 목적에는 웹 채널이 직접 기여합니다.
> 필수 요건 ④ 액추에이터는 아두이노가 구동하는 상태 표시부(신호등 LED · 7세그먼트 빈 좌석 수 · 부저)로 충족하며,
> 이는 AI 폴백 시연 장치를 겸합니다. **측정 방식·AI·인터럽트 설계는 신청서와 동일합니다.**"

- 요지: **주제 변경이 아니라 출력 채널 조정**입니다. 센서·AI·인터럽트·검증 방법은 그대로입니다.
- [ ] **교수님께 이 변경을 4주차 심사 전에 한 줄이라도 알려 둘 것** (사후 통보가 되면 불리합니다)

### 6-2. 보류 — 호스트가 정해진 뒤에 산다

| 품목 | 왜 지금 못 사나 |
|---|---|
| 라즈베리파이 본체 | **A/B/C안 미확정.** Pi 5(14~16만) ↔ Zero 2 W(2.5~3만) ↔ 학과 대여 |
| **CSI 카메라 모듈 ×2 + 케이블** | ⚠️ **케이블 규격이 보드마다 다릅니다.** Pi 4 = 15핀 / **Pi 5·Zero = 22핀 미니 FPC**. 보드 전에 사면 못 씁니다 |
| microSD | **저장장치 집행 가부 확인 중** ([예산회의 5절 #3](예산회의_0916.md)) |
| 방열판·케이스·전원 어댑터 | 보드 모델에 종속 |
| 거치대·브래킷 | **완제품 집행 불가** 우려 → 브래킷·프로파일 등 **재료성**으로 구성해야 함 |

### 6-3. 주문할 때 걸리는 규정 2가지

1. **배송비는 예산으로 못 냅니다.** 3만원 이하로 쪼개 여러 번 주문하면 배송비가 그만큼 **자비**가 됩니다.
   → 6-1을 **한 번에 묶어** 무료배송 기준(보통 3~5만원)을 넘기는 편이 유리합니다.
2. **주말·공휴일·22~05시 결제 불가 · 사업단 카드 대면 수령.**
   → **평일 낮**에 카드를 받아 그 자리에서 주문해야 합니다. 장바구니를 미리 만들어 두면 수령 당일에 바로 끝납니다.

> ✅ **오늘 할 것: 6-1을 디바이스마트 장바구니에 담아 총액 스크린샷 → 제안서 BOM 표에 그대로 붙이기.**
> 심사용 BOM은 [예산회의 4-5절](예산회의_0916.md)대로 **"학과 대여 시 0원 · 불가 시 자체 구매"** 조건부로 씁니다.
