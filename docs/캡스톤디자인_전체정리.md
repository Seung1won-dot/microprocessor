## 0-2. 수업 중 구두 공지 정리 (최신 — 문서와 다르면 이쪽 우선)

> 아래는 수업 시간에 교수님이 추가로 안내한 내용입니다. 배포 문서(신청 가이드·설명자료)와 수치가 다른 항목이 있어 별도로 정리합니다.

### 신청으로 얻는 것

- 신청의 실질적 목적은 **비용 지원**
- **일반형**: 1인당 **30만원** → 3인조 **90만원**, 4인조 **100만원**
- **기업연계형**: 일반형의 **3배 수준까지** 지원 가능
- **한 기업당 최대 2팀** 지원 가능

### 기업 매칭에 대해

- **귀찮은 일은 거의 없음.** 회사 담당자가 **동의사항에 사인만** 하면 되고, **회사 부담은 사실상 없음**
- 예산을 더 확보하고 싶다면 적극 고려할 것

### 비용 집행 (구두 안내 추가분)

- 카테고리 3종: **재료비 · 회의비(회계비) · 교통비**
- **재료비로 대부분을 소진하는 것을 권장** — 라즈베리파이, 하드보드지, 회로기판 등 과제와 직접 관련 있는 물품
- **회의비 상한 = 전체 신청 가능 금액의 20%** (예: 90만원 → 18만원)
- **1회 결제 3만원 이하** 기준 → 18만원을 한 번에 쓸 수 없고 **분할 사용 필요**
- **개인 카드 사용 불가** → **사업단 카드를 대면 수령한 뒤 결제**
- **문의 중 (답변 오면 안내 예정)**: LLM·AI 토큰 비용(OpenRouter 등), 3D 프린팅 등 소모성 재료비 포함 여부

### 신청서 작성 관련

- **디스플레이·반도체 계열 참여 체크는 필수** — 단, **실제 주제 아이템은 다른 영역이어도 무관**
- **추진 일정은 9~12월 범위**로 작성. 9월이 포함되지 않아도 무방
- 팀장이 **교수 이메일로 초안 보고** → 다음 주 **월·수 수업 시간에 2회 검토 기회**

### 팀 구성 (구두 안내)

- **수강생 37명**
- **3~4명 조 권장** — 비용 효율이 좋고, 라즈베리파이 수준의 하드웨어 완성도를 확보할 수 있음
- 2인조를 원하더라도 **4명까지 늘려 비용을 확보**하는 편을 권장
- **1인 개별 수행은 제한적으로만 허락** (교수·학과장 협의 필요)

### 캡스톤 미참가 선택지

- 캡스톤디자인에 신청하지 않고 **학술제만 출품하는 것도 가능**
- 단, **비용 지원이 없어 하드웨어를 자비로 조달**해야 함

### ⚠️ 문서와 구두 공지의 차이 (확인 필요)

| 항목 | 배포 문서 | 수업 중 구두 공지 | 대응 |
|---|---|---|---|
| 신청 마감 | 9/11(금) 10시 | **9/10(목) 10시** | 9/10 기준으로 준비 |
| 일반형 지원금 | 1인당 **10만원** | 1인당 **30만원**으로 전달됨 | 문서 기준(10만원)이 맞는 것으로 정리 |
| 기업연계형 지원금 | 1인당 **30만원** | 일반형의 **3배 수준** | 서로 일치 — **우리 팀은 이쪽** |
| 수강 인원 | 27명(정원) / 30명 | **37명** | — |
| 1인 단독 수행 | 불가 (수강 취소 권고) | **제한적 허락** (교수·학과장 협의) | 사실상 팀 구성 필수 |
| 4인조 금액 | 1인당 단가 × 4 | **100만원 (상한 성격)** | 신청 시 확인 |

> ※ 지원금 단가 차이는 **우리 팀 기준으로는 정리됨** — 아래 0-3절 참고.
> (구두 공지의 "1인 30만원"은 **기업연계형** 단가이며, 배포 문서와 일치합니다. 일반형은 1인 10만원.)

| 항목 | 한도 | 비고 |

| **재료비 + 교통비** | 나머지 **960,000원 이상** | 교수님 권장: **재료비로 대부분 소진** |

- 라즈베리파이 5 + 카메라 + 센서·액추에이터 + 케이스/구조물까지 충분히 커버되는 규모

- 결제는 **사업단 카드 대면 수령** 후 진행 (개인 카드 불가)

### 기업 매칭 — 교수님이 처리

> ✅ **기업 섭외·매칭은 교수님이 알아서 진행해 주시기로 했습니다.** 팀이 기업을 직접 찾을 필요 없음.

우리가 신경 쓸 부분은 **기업 정보가 확정된 뒤 신청서에 옮겨 적는 것**뿐입니다.

| # | 항목 | 담당 | 비고 |
|---|---|---|---|
| 1 | 참여 기업 확정·섭외 | **교수님** | 한 기업당 최대 2팀 |
| 2 | 산학연계교육 운영 협약서 (기업 서명) | **교수님** | `캡스톤 관련 서류/02.` 서식 |
| 3 | 기업 개인정보 동의서 (기업 서명) | **교수님** | `캡스톤 관련 서류/03.` 서식 |
| 4 | 기업정보 입력 (기업명·대표자·사업자번호·주요 생산품·주소·홈페이지·담당자) | **팀장** | 교수님께 정보 받은 뒤 입력 |
| 5 | **기업 수요내용** 입력 | **팀장** | 사업자번호로 자동 조회돼도 **이 항목만은 직접 입력** |
| 6 | **산학연계 교육과정 운영 내용** 요약서 (**250자 이상**) | **팀 전체** | 참여기업 및 대학의 역할·활동 내용 |
| 7 | 수업계획서 첨부 시 **기업명 + 기업 수요내용 포함** | **팀장** | |

> 💡 사업자번호를 먼저 입력해 조회했을 때 **이미 등록된 기업이면 정보가 자동 입력**됩니다.
> 조회되지 않으면 직접 입력하거나, 참여기업이 앵커사업단 홈페이지에 가입하면 자동 등록됩니다.
>
> ⏳ **6번(산학연계 교육과정 운영 내용, 250자 이상)이 팀의 실질적 숙제입니다.**
> 기업이 어디로 정해지는지에 따라 내용이 달라지므로, **교수님께 기업 정보를 언제 받을 수 있는지 먼저 확인**해야 합니다.

### 2-2. 추가 필수 요건

1. **최소 한 곳 이상 인터럽트 사용** (어디에 쓸지 제안서에 명시)
2. **AI 추론 지연/실패 시 대체 동작(폴백) 정의** — 특히 "AI 무응답 3초 시 동작은 무엇인가"에 답해야 함
3. **실제로 존재하는 문제**를 대상으로 하고, 그 문제를 겪는 대상과 근거(인터뷰·통계·현장 관찰)를 제안서에 제시
4. 요건 미충족 제안서는 반려 → **1주 이내 재제출**

- AI 없는 단순 제어
- 하드웨어 없는 AI 데모

## 8. 캡스톤디자인 온라인 신청 절차

### 8-1. 전체 프로세스

```
홈페이지 가입  →  온라인 신청  →  팀원 요청 승인  →  교수 승인  →  사업단 승인
  (팀원 전체)      (팀장)          (팀원 전체)        (교수)       (사업단)
```

### 8-2. 단계별 방법

1. **홈페이지 가입 (팀원 전원)** — https://anchor.sch.ac.kr → 상단 LOGIN → 학생/교직원 → 포털 계정 로그인 → 로그인정보·개인정보 추가 입력 → 약관 동의
   - ※ **팀원 전원 가입 완료 후**에야 팀장이 팀원 등록 가능. 가입 완료 시 팀장에게 알릴 것
2. **온라인 신청 (팀장)** — 상단 메뉴 → 온라인 신청 → 학생지원 프로그램 → 좌측 메뉴 → 캡스톤디자인 → 프로그램 선택 후 신청
3. **팀원 요청 승인 (팀원 전원)** — MY PAGE → 캡스톤디자인 관리 → 캡스톤 팀원요청 → 보기 → 내용 확인 → 개인정보수집동의서 서명 → 요청 동의하기
4. **교수 승인 → 사업단 승인** → 최종 승인 시 MY PAGE > 캡스톤디자인 관리에서 과제 확인

### 8-3. 신청 현황 확인

MY PAGE → 캡스톤디자인 관리 → 캡스톤 신청현황 → 캡스톤디자인 프로그램 정보

| 처리현황 | 의미 |
|---|---|
| 구성원 승인중 | 팀원 또는 지도교수 승인 전 |
| 승인대기 | 팀원·교수 승인 완료, 사업단 검토 중 |
| 반려 | 사업단 검토 중 오류 발견 → **작업 > 수정**으로 반려사유 확인 후 재제출 (재제출 시 팀원·교수 재승인 불필요) |

- 팀장은 팀원 승인 현황을 직접 확인하고 미동의 팀원에게 요청 → **팀원 전원 승인 후에야 교수 승인 가능**
- **작업 > 취소**를 누르면 내역이 삭제되어 처음부터 다시 작성해야 함

### 8-4. 팀원 추가가 안 되는 경우 체크리스트

1. 팀원 전원이 가입(로그인정보·개인정보 추가입력)을 완료했는가
2. **같은 수강번호** 수강생인가 (분반 운영으로 수강번호가 다르면 사업단 연락)
3. 한 명이 같은 교과목에서 다른 팀에 이미 들어가 있지 않은가
4. 2인 이상인가 (1인 팀 불가)

## 10. 예산 집행 규정

### 10-1. 항목별 기준

| 구분 | 내용 및 제한 |
|---|---|
| **재료비** | 과제와 직접 관련 있는 재료성 물품. 사무용품·완제품 불가. 구매금액 합 300만원 미만, **해외결제·유료 프로그램 결제 불가**, **마일리지 적립되는 결제 불가**(예: 네이버페이 적립) |
| **회의비** | 팀 회의 식대·다과비. **최대 신청 금액의 20%까지**. 하루 1회, 회의 1시간 이상, 식대/다과비 중 **하나만** 선택(동시 집행 불가). 1인당 30,000원. 대상은 지도교수·참여 학생·참여 기업. 식대는 회의 종료 후, 다과비는 시작 전 결제. 장소대여비·관외 지역 사용 불가 |
| **교통비** | **가능**: 시외/고속버스(일반실), 기차·KTX(일반실) / **불가**: 시내버스·지하철·택시·렌트·유류비·프리미엄·특실, 통학, 활동 장소가 학교인 경우, 물품 구입용 교통비, 팀원 아닌 외부 인원 교통비·출장비 |

> 교수님 권장: **재료비로 대부분을 소진**할 것 (라즈베리파이, 하드보드지, 회로기판 등). 회의비도 가능하나 쓰는 과정이 생각보다 복잡함.

### 10-1-2. 결제 방법 (수업 중 구두 공지)

- **개인 카드 사용 불가** → **사업단 카드를 대면 수령한 뒤 결제**
- **1회 결제 3만원 이하** 기준 → 회의비 한도(예: 90만원의 20% = 18만원)를 한 번에 쓸 수 없고 **여러 번 나누어 사용**해야 함
- **포함 여부 문의 중** (답변 오면 안내 예정): LLM·AI 토큰 비용(OpenRouter 등), 3D 프린팅 등 소모성 재료비

### 10-2. 집행 불가 항목 (체크리스트)

- 과제와 관련 없는 항목 / 과제기간 이후 집행
- **주말·공휴일 및 22:00~익일 05:00 사용 불가**
- 사무용품, 완제품(재료성 물품이 아닌 것)
- 범용 기자재 (핸드폰, 카메라, 가구, 프린터, 토너, A4용지 등)
- 마일리지 적립 결제 (네이버페이, 해피포인트 등)
- 이어폰·키보드·마우스·스피커 등 전자기기
- **PC 및 PC 관련 용품·부품·소모품, 소프트웨어, USB 등 저장장치**
- 증빙서류(영수증·사진) 부재 — **간이영수증 불가**
- 자동차 렌트·유류비·숙박비 / 출장비 / 인건비·외부 위탁 용역비
- 상품권·문화상품권·기프티콘·기념품·답례품·경품 / 어플리케이션·폰트·이미지
- 설문조사·이벤트 참여자에 대한 대가성 물품
- 사업자등록번호 없는 사업장 / 내부거래(학교·산단 사업자번호) / 주류 및 유흥업소

- 배송비(시제품 배송비, 착불 배송비, 반품 택배비)
- 의류(기념 티셔츠·앞치마·가운)·가방·신발·액세서리 / 학원 수강료·자격증 응시료

## 11. 하드웨어 · 개발환경

### 사용 보드

- **아두이노 우노 R3 (ATmega328P)** 31대로 통일
- 1주차 **수요일에 한 대씩 배부**, 보드마다 번호 부착 → 학기 중 본인 번호로 사용
- 집에 가져가도 되고 실습실에 두고 써도 됨
- 교재는 ATmega128이지만 같은 AVR 계열 → 레지스터 이름이 거의 그대로 매핑, 차이는 **대조표 한 장**으로 배포

### 수요일 전 준비물 (필수)

- [ ] **Arduino IDE 2.x 설치 완료** (arduino.cc) — 현장에서 30명이 설치하면 75분이 다 날아감
- [ ] **노트북 지참** (설치까지 끝난 상태로)
- [ ] USB-A 포트가 없으면 **허브 또는 젠더** (우노 케이블은 납작한 USB-A, 요즘 노트북은 USB-C만 있는 경우가 많음)
- [ ] 집에 **USB-B 케이블**(옛 프린터·외장하드용 네모난 플러그)이 있으면 지참 (케이블은 공용으로 돌려 씀)
- [ ] 노트북이 없으면 **미리 알릴 것** → 실습실 PC 배정

### 수요일(1주차 실습)에 할 일 — 75분 안에

1. 번호 붙은 우노 배부 (케이블은 공용)
2. USB 연결 → 보드·포트 선택 → 첫 업로드
3. 레지스터로 같은 동작 다시 쓰기
4. 실습 검사 #1
5. 팀 구성 마무리

### 기자재

아두이노 / 라즈베리파이 보드(실습실 기보유 위주, 추가 구매 예정), 각종 센서·액추에이터, 단일보드컴퓨터(라즈베리파이), USB 카메라, 실습용 PC

### 안전

모터·전원 등을 다루는 실습·프로젝트는 지정된 안전 수칙 준수. **장비 파손 시 즉시 담당 교수에게 보고**

## 12. 이론 내용 요약 (1주차)

### 마이크로프로세서 시스템의 구성

- CPU 하나로는 아무것도 못 한다 → **버스**로 연결
  - **주소 버스** — 어디를 볼 것인가
  - **데이터 버스** — 무엇을 주고받는가
  - **제어 버스** — 읽는가 쓰는가
- 여기에 **RAM · ROM · 인터페이스 회로**가 붙어야 시스템이 된다
- 2주차에 이 그림을 **레지스터 주소**로 다시 본다

### MPU vs MCU — "층이 없다는 것의 의미" (이 과목의 척추)

| | 노트북 (계층화 구조) | MCU (혼합형) |
|---|---|---|
| 구조 | 응용 → OS → BIOS → 하드웨어 | 내 코드가 곧 하드웨어를 직접 만짐 |
| 하드웨어 접근 | OS에게 부탁해서 만짐 | 직접 |
| 실행 시점 | 알 수 없음 | **내가 안다 (결정성)** |
