# PRODUCT.md · 밥먹을래말래

## 무엇
학생회관 1층 식당의 지금 혼잡도와 빈 자리를 카메라로 세어 보여주는 웹 앱. 홈 화면에 추가해 앱처럼 쓴다.

## 누가, 언제
- 점심 직전 강의실에서 나오며 휴대폰으로 **3초 안에** "지금 가도 되나"를 확인하는 학생
- 친구와 "어디 앉지?"를 정할 때 구역별 빈 자리를 보는 학생
- 대부분 휴대폰 세로 화면, 한 손. PC는 보조.

## 답해야 하는 질문 (중요한 순서)
1. 지금 가면 앉을 수 있나? → 판정 한 줄 + 빈 테이블 수
2. 주문 줄은 얼마나? 배식대는 열었나? → 주문 대기, 배식대 영업 상태
3. 어디가 비었나? → 구역 카드, 배치도
4. 평소엔 언제 붐비나? → 시간대 그래프, 구역별 붐비는 때

## 느낌
가볍고 친근하지만 숫자는 믿음직하게. 학교 공지 같은 딱딱함도, 광고 같은 화려함도 아닌 "잘 만든 동네 앱".

## 하지 않는 것
- 카메라·집계 방식 같은 만든 사람 쪽 정보를 학생 화면에 늘어놓지 않는다 (팀 통계 `/stats`에서 본다)
- 영상·사진을 보여주지 않는다 (영상은 저장·전송하지 않음)

토스(숫자 하나를 크게), 배민(친근한 말투), 지도 앱의 실시간 혼잡도 표시
